# AI Test · 大模型与 Agent 测评笔记

> 一份系统性的 AI 测评学习笔记：从基础概念、行业前沿，到企业落地方案。
> **每条事实性知识都附权威来源**，可逐条溯源。

---

## 这是什么

大模型时代的"评测"（evaluation）已经从"跑个测试用例"变成一门独立的工程学科：模型级基准、LLM-as-Judge、RAG 测评、Agent 测评、在线实验、评测工具链、合规要求……概念多、更新快，且**大量中文资料的引用已经过时**。

这份笔记试图把散落的测评知识整理成一张**有层次、可溯源、跟得上变化**的地图：

- **有层次**：按「基础知识 → 企业落地 → 行业前沿」组织，先建立判断力，再谈工具与落地。
- **可溯源**：事实性陈述均给出权威来源（论文 / 官方文档 / 官方标准页），并标注验证状态。
- **跟得上**：单列「时效地图」，集中记录已停更、已换代、已更名、已关停的事实，避免引用过时信息。

## 怎么读

- **速览（半天）**：第 1 → 2 → 3 → 5 → 6 → 13 章，建立"测什么、怎么落地"的骨架。
- **工程实践**：第 2 → 6 → 12 → 13 章，聚焦方法论与 CI/CD。
- **面试准备**：第 6 章 + 附录 F（Agent 面试真题与答案），方法论部分回看第 2 章。
- **完整学习**：从第 1 章顺序读到第 16 章。
- **速查**：直接翻附录 A（术语）、C（时效地图）。

## 内容原则

1. **不杜撰**：所有事实性结论必须能追溯到权威来源；找不到来源的内容会显式标注。
2. **标注时效**：涉及版本、日期、维护状态的信息，以核对日期为准；变动集中收录在附录 C。
3. **深入浅出**：不推导公式、不教调参，目标是"能正确使用术语、能判断指标选得对不对"。
